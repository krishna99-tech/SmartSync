System Architecture

How SmartSync Works

Three interconnected layers guarantee instant responsiveness, offline awareness, and maximum security.

Edge Hardware

1. ESP32 Node Relays

Micro-controllers execute low-level C++ firmware, listening directly on secure WebSocket channels and pulsing hardware pins for lights, AC units, and switches.

Cloud Engine

2. Firebase Realtime DB

Push-based data trees synchronize state changes globally under 100ms. An automated heartbeat pings the node to immediately identify if the controller loses power or Wi-Fi.

Client Layer

3. Flutter Mobile App

Compiled natively to machine code for Android. Features masked instance keys, tactile touch triggers, customizable device names, and automatic credential handoffs.

Common Inquiries

Frequently Asked Questions

Why was the app upgraded to Flutter?
The Flutter upgrade replaces the previous hybrid React Native framework with a high-performance Ahead-Of-Time (AOT) compiled native binary. This delivers instant app startup, ultra-responsive 120 FPS animations, and seamless Firebase Realtime Database socket communication.
Where are previous versions (v1.0 - v1.6)?
All older versions have been phased out due to security patches, improved WebSocket protocol formats, and the migration to the unified Flutter codebase. The new v2.0.0 APK is backwards-compatible with all existing ESP32 installations.
How does the ESP32 know my user account?
Your account has a unique 28-character Instance Key (Firebase User ID) shown in the app dashboard. Flashing this UID into your ESP32 Arduino / PlatformIO sketch creates a dedicated private database channel.
Is my data private and secure?
Yes. All communication is protected through TLS 1.3 encryption and authenticated via Firebase Security Rules, ensuring only your verified account can read or write to your devices.
